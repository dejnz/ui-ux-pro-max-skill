# assets/

Bu klasördeki `g*.jpg` ve `gif-*.gif` dosyaları **placeholder**'dır (yazılım ile üretilmiş
düz renk kartlar). Yayına almadan önce gerçek fotoğraflarla değiştirin — dosya adları aynı
kalmalı:

- `herovid.mp4` — ana sayfa hero videosu (repoda yok, eklenmeli; 1080p+, sessiz oynatılır)
- `g01.jpg g02.jpg g03.jpg g05.jpg g06.jpg g07.jpg g09.jpg g10.jpg g11.jpg g13.jpg g14.jpg g16.jpg`
  — gelin fotoğrafları (dikey, ~3:4 oran önerilir)
- `gif-gelinlik.gif`, `gif-haute-couture.gif`, `gif-after-party.gif` — koleksiyon görselleri

`site.css` ve `site.js` alt sayfaların ortak altyapısıdır — silmeyin.
